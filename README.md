# 🚀 نظام أتمتة النشر الأكاديمي الذكي V4.0 (Booooot_ADMAN)
### الإصدار المعماري المنفصل بالكامل (Twitter + Telegram + AI Engine)

نظام أتمتة شامل ومستقل مصمم ليعمل بكفاءة عالية على بيئة **Termux (Android)** أو أي خادم لينكس/سحابي، مع لوحة تحكم ويب تفاعلية باللغة العربية وإدارة دقيقة بدون أي اعتمادات على واجهات برمجة رسمية مدفوعة.

---

## 🏛 المعمارية الهندسية المنفصلة (Modular Architecture)

تم فصل النظام إلى وحدات مستقلة تماماً منعاً لأي تداخل برمجي أو تعارض في الجلسات:

```
Booooot_ADMAN/
├── ai_engine/               # النواة الإدراكية والذكاء الاصطناعي
│   ├── ai_memory.py         # قاعدة الذاكرة ومنع التكرار (bot_memory.db) والتعلم التراكمي
│   ├── ai_provider.py       # المزود المزدوج (HCNSEC API + Cookie AI Sessions)
│   └── smart_ocr.py         # المعالجة البصرية فائقة الدقة (MiniCPM-V-4.7-35B)
├── twitter/                 # محرك تويتر المستقل (بدون API رسمي)
│   ├── twitter_crawler.py   # سحب التغريدات عبر الكوكيز (twscrape) ومنع التكرار
│   ├── twitter_publisher.py # توليد البطاقات الصورية ونشر التغريدات
│   └── twitter_proxy.py     # تدوير البروكسيات من proxies.txt لحماية الحسابات
├── telegram/                # محرك تيليجرام المستقل (Bot API + UserBot Telethon)
│   ├── telegram_bot.py      # البوت الرسمي وإدارة الأوامر والتوجيه
│   ├── telegram_forwarder.py# صياغة المنشورات وتنسيق التواريخ واستبدال الأرقام
│   └── telegram_ocr.py      # سحب بروشورات الإعلانات وفك خطوطها بالذكاء البصري
├── bot_database.db          # قاعدة البيانات التشغيلية (WAL mode)
├── bot_memory.db            # قاعدة بيانات الذاكرة والتعلم التراكمي لمنع التكرار
├── proxies.txt              # قائمة البروكسيات المعتمدة للتدوير
├── server.ts                # خادم لوحة تحكم الويب (Express + Vite)
└── backup.sh                # سكربت النسخ الاحتياطي التلقائي لمجلد التنزيلات
```

## ⚡️ الميزات الجوهرية للنظام

1. **معالجة بصرية فائقة الدقة (Vision OCR) للبروشورات والصور الأكاديمية**:
   - حل نهائي لمشكلة عجز تيليجرام وتويتر عن قراءة نصوص وتفاصيل إعلانات الجامعات المصممة بالخطوط العربية المعقدة.
   - استخدام نموذج الرؤية البصرية المتقدم `MiniCPM-V-4.7-35B-A3B` عبر منصة HCNSEC لتحويل الصور إلى بيانات نصية موثقة (مواعيد، شروط، نسب قبول، قاعات، روابط).

2. **الاستبدال الأوتوماتيكي لأرقام التواصل ومعرفات المساعدة**:
   - عند اكتشاف أرقام هواتف أو معرفات لمنسقي بحوث أو إعلانات خارجية في المنشورات الموجهة، يقوم النظام آلياً باستبدالها بمعرف المشرف الرسمي:
     - **معرف المشرف المعتمد:** `@M_S_F_G`
     - **المعرف الرقمي للمشرف:** `7607633343`

3. **حلقة التغذية الراجعة والتعلم من التاريخ (Feedback Loop)**:
   - ذاكرة تراكمية (`bot_memory.db`) تسجل أسباب الرفض والملاحظات (مثل استبعاد إعلانات الكافيهات، والبحوث التجارية المدفوعة، وروابط الإعلانات الشخصية).
   - تُحقن هذه القواعد تلقائياً في سياق الذكاء الاصطناعي لمنع الأخطاء مستقبلاً.
   - كاش منع تكرار (Deduplication) يعتمد على الهاش الفريد لكل محتوى.
   - أرشفة وتنظيف تلقائي للسجلات الأقدم من 90 يوماً وضغط قاعدة البيانات (`VACUUM`).

4. **نظام الذكاء الاصطناعي المزدوج (Dual AI Engine)**:
   - **المزود الأساسي (Primary API)**: نموذج `DeepSeek-V4-Flash` للنصوص والتنقيح، ونموذج `MiniCPM-V-4.7-35B-A3B` للبصريات عبر HCNSEC.
   - **المزود الثانوي (Cookie AI Provider)**: جلسات كوكي مسجلة في `data/ai_sessions/` لتوليد البطاقات والردود التفاعلية بدون تكلفة إضافية.

5. **استقلالية تامة عن الـ APIs الرسمية المدفوعة**:
   - **تويتر**: يعمل بمكتبة `twscrape` عبر الكوكيز (`auth_token` و `ct0`).
   - **تيليجرام**: يعمل بمكتبة `Telethon` لقراءة القنوات العامة والخاصة، مع `python-telegram-bot` للنشر الرسمي.

## 📲 خطوات التثبيت والتشغيل على Termux (Android)

### الخطوة 1: تحديث الحزم وتثبيت المتطلبات الأساسية
افتح تطبيق Termux ونفذ الأوامر التالية سطر بسطر:
```bash
pkg update -y && pkg upgrade -y
pkg install -y git python nodejs-lts sqlite tesseract ffmpeg
```

### الخطوة 2: استنساخ المستودع والدخول للمجلد
```bash
git clone https://github.com/mstfy737216610-prog/Booooot_ADMAN.git
cd Booooot_ADMAN
```

### الخطوة 3: التثبيت السريع والتلقائي للحزم
```bash
bash termux_install.sh
```
*سيقوم السكربت بتثبيت كافة مكتبات البايثون (`telethon`, `twscrape`, `httpx`, `aiohttp`, إلخ) ومكتبات الواجهة (`npm install`).*

## 🎮 طرق التشغيل المرنة

وفرنا لك سكربتات تشغيل مستقلة لتختار ما يناسب جهازك وظروف بطاريتك:

### 1. تشغيل واجهة الويب فقط (للإدارة وتعديل الإعدادات دون تشغيل البوت في الخلفية):
```bash
bash تشغيل_الواجهة_فقط.sh
```
*تفتح الواجهة مباشرة على المتصفح: `http://localhost:3000`*

### 2. تشغيل بوت النشر التلقائي فقط في الخلفية (دون استهلاك موارد للويب):
```bash
bash تشغيل_البوت_فقط.sh
```

### 3. تشغيل النظام بالكامل (الواجهة + البوت معاً):
```bash
bash termux_start.sh
```

## 💾 النسخ الاحتياطي التلقائي (Backup)

لحفظ كافة قواعد البيانات والجلسات والإعدادات بنقرة واحدة إلى مجلد التحميلات بالهاتف:
```bash
bash backup.sh
```
*يتم حفظ أرشيف مضغوط باسم `Booooot_ADMAN_backup_*.tar.gz` في `/sdcard/Download/` مباشرة.*
