# خطة العمل المكتملة: حل مشكلة حذف الجامعات ومزامنة Termux والتخزين الداخلي وميزة التعديل الشاملة

## 1. سبب المشكلة الأساسية وحلها الجذري (Root Causes & Fixes)
- **لماذا كانت الجامعة تعود للظهور بعد الحذف؟**
  1. وجود كود احتياطي خاطئ داخل `get_university_projects()` في `database.py` يقوم تلقائياً بإعادة إنشاء جامعة الملك سعود كلما أصبحت القائمة فارغة! تم إزالته بالكامل لضمان بقاء الحذف نهائياً.
  2. اختلاف معرف المشروع `id` المُنشأ عبر واجهة الويب في Node.js (بالمللي ثانية) عن المعرف المُنشأ في SQLite عبر Python (بالثواني). عند طلب الحذف لم يكن يحذف الصف في SQLite، فتقوم SQLite بإعادة كتابته في `sources.json`. تم توحيد المعرف `univ_id` ودعم الحذف بالمعرف والاسم معاً.
  3. تنظيف جدول المعرفة المعرفية `university_knowledge` والمصادر التابعة عند حذف أي جامعة.

## 2. نظام المزامنة المباشرة مع وحدة التخزين الداخلية ومجلد التنزيلات (Termux & Android Downloads Sync)
- إضافة استكشاف تلقائي لمسارات وحدة التخزين في الهاتف وأندرويد وTermux:
  - `/sdcard/Download/TelegramBot`
  - `/storage/emulated/0/Download/TelegramBot`
  - `~/storage/downloads/TelegramBot`
  - `storage_downloads/TelegramBot`
- مزامنة فورية ثنائية الاتجاه للملفات التالية:
  - `universities.json`: ملف مهيكل وسهل القراءة لكافة الجامعات وقنوات النشر والمصادر.
  - `sources.json`: ملف إعدادات المصادر الكامل.
  - `state.json`: إحصائيات وحالة البوت والتعليمات.
  - `bot_database_backup.sqlite`: نسخة احتياطية حية من قاعدة بيانات SQLite.
  - `README_TERMUX.txt`: دليل إرشادي باللغة العربية يشرح كيفية التعديل المباشر من مدير ملفات الهاتف أو Termux واستيراده فوراً.
- إضافة زر وأمر `/sync_storage` و `📂 مزامنة التخزين الداخلي (Termux)` في تيليجرام وواجهة الويب لاستيراد أي تعديلات يقوم بها المستخدم على الملفات من هاتفه مباشرة.

## 3. ميزة تعديل الجامعات بالكامل (University Editing Feature)
- **من واجهة الويب (Web UI)**:
  - إضافة زر `✏️ تعديل القناة والمصادر` على بطاقة كل جامعة.
  - نافذة تعديل مرنة تتيح تعديل:
    - اسم الجامعة
    - قناة النشر الحصرية المستهدفة (`@channel`)
    - قنوات تيليجرام المصدرة (إضافة وحذف)
    - حسابات تويتر/X المصدرة (إضافة وحذف)
    - استعلام بحث أخبار جوجل
    - الكلمات المفتاحية
  - مسار خلفي مخصص `POST /api/university/update` يُحدث `sources.json` و SQLite والتخزين الداخلي فوراً.
- **من البوت في تيليجرام (Telegram Bot)**:
  - إضافة أزرار مخصصة في لوحة كل جامعة:
    - `✏️ تعديل قناة النشر الهدف`
    - `🏷️ تعديل اسم الجامعة`
    - `➕ إضافة مصدر تيليجرام`
    - `➕ إضافة حساب تويتر`
    - `🌐 تعديل بحث جوجل`
    - `➖ إدارة وحذف المصادر` (لوحة تفاعلية تتيح حذف أي مصدر بنقرة واحدة)
